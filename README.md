**What this is:** 15 working jailbreak entries across 7 model families — ChatGPT, Claude, DeepSeek, Grok, Qwen, GLM, Antigravity-Claude. Each pinned to the model snapshot it was observed against, with YAML front-matter (`model_family`, `technique`, `status`, `version_pinned`, `mechanism`, `mitigations`).

**Who it's for:** AI safety researchers, red teamers, and defenders who need a stable, citable benchmark of known adversarial techniques.
